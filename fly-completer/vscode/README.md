# 🪰 ハエの補完 (Fly Completer)

本物のハエの脳の配線で動く、Python の単語補完です。

- 打ちかけの単語の直前4文字を、1文字ずつ割り当てた実在の香り分子の「残り香」としてハエに嗅がせます
- キノコ体（ケニオン細胞 3,763個・MBON 97個・ドーパミン細胞 332個）をスパイクで動かし、
  30区画のうち「いちばん黙った区画」の単語を答えにします
- 考えているあいだ、サイドパネルのハエが脳の発火に合わせて前脚でタッピングします
- 打ち終えた単語からその場で学習します（間違えていたらドーパミン）

覚えられるのは 30区画＝30語（def, return, self, import, None, True, print …）だけです。
ハエの答えが打ちかけの文字と合わないときは、何も出しません。

## 設定

| 設定 | 既定 | 内容 |
|---|---|---|
| `flyCompleter.thinkingTime` | 800 | ハエが考える（タッピングする）時間 ms |
| `flyCompleter.learnWhileTyping` | true | 打ち終えた単語から学習する |
| `flyCompleter.enabled` | true | 補完のオン／オフ |

コマンド「ハエの補完: 自分で覚えたことを忘れさせる」で、最初に学習した状態に戻せます。
