# 🪰🍷 ハエのワインソムリエ

本物のハエの脳の配線（雄CNSコネクトーム）で、自分のワインの好みを覚えさせるWebアプリ。
左にハエの体（NeuroMechFly）、右に脳（本物のニューロンの形）を並べて3D表示し、
ハエがワインの雫に近づいて嗅ぎ、脳で判断し、飲むか逃げるか、そしてドーパミンで学習するまでを見せる。

## 動かし方

`web/index.html` をブラウザで開くだけ（サーバー不要・オフラインで動く）。教えた履歴はブラウザの中（localStorage）に保存される。
脳とハエの3Dデータは共通部品 `../fly-core/data/` から読むので、リポジトリ全体をそのまま置いておくこと。

ほかの端末から試すなら、リポジトリのいちばん上で：

```
python3 -m http.server 8000
# http://<MacのIPアドレス>:8000/fly-sommelier/web/ を開く
```

## 遊び方

画面上の切り替えで、本物のハエの学習実験と同じ「訓練」と「テスト」の2つのページを行き来する。

**しつける（訓練）**
1. ボトルを押し、ラベルにある香り（任意）と「砂糖をあげる（好き）／電気を流す（苦手）」を選ぶ
2. ハエが雫のそばで匂いを嗅ぎ、砂糖が落ちてきて舐める／床の電極から電気ショック
3. 脳の窓が全画面になり、①匂いが届く →②ケニオン細胞が光る →③ドーパミンが区画へ流れる →④結合が弱まる（近づく出力・避ける出力が何％変わったか）

**当ててもらう（テスト）**
1. ボトルを押すと一滴たれて、ハエが歩いてきて嗅ぐ（香りはアイコンから足せる）
2. 脳の窓が全画面になり、①②③判断 → ハエが飲む／逃げる／離れる。ここでは学習しない
3. 「あなたの好みと合っていましたか？」に答えると、ソムリエLv（直近15回の的中率）に反映。「違った」なら「このワインをしつける」でそのまま訓練へ

左の道具から「記録（しつけ・テスト）」「実験」「この脳について」を開ける。

## ハエの体と動き

- 体：NeuroMechFly v2（X線CTで撮った本物のハエから作られた3Dモデル、69の体節）
- **歩く**：本物のハエの歩行で測った関節角度の記録（flygym 同梱）を平滑化して再生。速さも記録から推定（約11 mm/s）。画面では0.35倍のスロー
- **触角で嗅ぐ／前脚でトントン味見／口吻を伸ばして飲む／飛び立つ**：関節を手で動かしたアニメーション（記録ではない）
- 行動の選び方：脳の「総合」の好き度が +0.15 より上なら味見して飲む、−0.15 より下なら飛んで逃げる、そのあいだは少し離れる

## 仕組み

```
ワイン（品種＋香りの言葉）
  → 香り分子の混ざり具合               data/wine_dictionary.json（手作りの辞書）
  → 糸球体 47個の反応                  DoOR の受容体応答データ
  → 投射ニューロン(PN) 254本           雄CNSの ORN→PN 配線
     ├→ ケニオン細胞(KC) 3,763本        雄CNSの PN→KC 配線。上位5%だけ発火
     │    → MBON 37タイプ               雄CNSの KC→MBON シナプス約42万個が初期値
     │         ↑↓ ドーパミン細胞 23タイプ（PAM＝ごほうび / PPL1＝罰）
     └→ 側角(LH) 422タイプ              雄CNSの PN→LH 配線（生まれつきの好み）
```

- **MBONの向き**：その区画に主に入るドーパミン細胞で決める（データから自動）。PAM が入る区画の MBON は「避ける」、PPL1 なら「近づく」。37タイプが 15 / 22 にきれいに分かれた
- **学習**：👍 で PAM、👎 で PPL1 が発火。その区画で「いま発火した KC → MBON」の結合を弱める（ハエで知られている可塑性）。ドーパミンがなければ少しずつ元に戻る（忘却）
- **報酬予測誤差**：式では与えていない。MBON → ドーパミン細胞のフィードバック（本物の配線）から出てくるかを見る
  - グルタミン酸を「興奮」と扱うと、学習が進むほどごほうびのドーパミンが減る（予測誤差らしい）
  - 「抑制」と扱うと、逆に増える。どちらが正しいかは未解決なので、「実験」タブで切り替えられる
- **生まれつきの好み**：行動実験で好き嫌いがはっきりしている糸球体7個だけに印（`data/innate_valence.json`）。そこから先は PN→側角の本物の配線で伝える。全ワイン共通の土台の匂いとの差で評価
- **総合** ＝ 教わった好み ＋ 0.5 × 生まれつきの好み

## データを作り直す

コネクトームの読み込みと、糸球体 → PN → KC の選び方は共通部品 fly-core（`../fly-core/pipeline/mcns.py`）を使う。

```
pip install -r requirements.txt      # = ../fly-core/requirements.txt
python pipeline/build_data.py        # 配線と匂いのデータ → web/data/app_data.js
```

3D表示のデータ（脳のニューロンの形・ハエの体）は fly-core 側で作る：

```
python ../fly-core/pipeline/build_scene3d.py   # → ../fly-core/data/scene3d.js
python ../fly-core/pipeline/build_fly_body.py  # → ../fly-core/data/fly3d.js（flygym が必要）
```

初回は雄CNSの結合データ（約500MB）と骨格約4,500本をダウンロードして `fly-core/raw/` に保存する（ほかのアプリと共用、neuPrint のトークンは不要）。

## 注意・限界

- 辞書の数値は「目立ち具合」の目安で、実際の濃度ではない
- バニラ（樽）、フラネオール（いちご飴）、4-エチルフェノール（革）、ジオスミン（カビ）は受容体データが少ない。βダマセノン、ロタンドン、ローズオキシドは DoOR になく、辞書に入れていない
- 受容体データが測られていない組み合わせは「反応なし」として扱っている
- PN→KC は本物でもランダムでも予測の当たり方がほぼ同じ。PN→KC がほぼランダムという既知の報告（Caron et al., Nature 2013）と合っている
- 3D表示のニューロンは、短い枝を切り落として間引いた形
- ハエの体は物理シミュレーションではなく、関節角度をそのまま当てている（足が少し滑って見えることがある）
- PC向けの画面。スマホでも動くが、ボトル棚や脳の窓が画面を大きく占める
